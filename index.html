📊 柱量圖判讀（外資／投信／量價）
量價柱：高度=成交量大小，顏色=漲跌方向
放量上漲（柱高+紅）→ 主力積極買進，最強訊號
縮量上漲（柱矮+紅）→ 惜售，賣壓不重
放量下跌（柱高+綠）→ 主力出貨，最危險
縮量下跌（柱矮+綠）→ 正常回檔整理
外資賣+放量上漲 → 有其他主力承接，背離訊號
三根全紅 → 最強多方共識
三根全綠 → 最強空方，嚴格停損
※ 單天訊號不可信，需連續3天以上確認
📋 五天綜合判斷（柱量圖下方）

籌碼：外資投信近5天買賣方向
量能：近5天量比趨勢（遞增／萎縮／持平）
動能：日MACD近5天能量方向
KD：日K位置與方向
四項多數同向偏多 → 可持續關注
四項多數同向偏空 → 建議謹慎評估
※ 籌碼賣超但量能放大，恐為出貨訊號，需特別留意
📉 日KD位置 / 日MACD能量
日KD位置：判斷超買超賣區間
日K < 20 → 超賣低檔，空間大
日K 20-80 → 正常區間
日K > 80 → 超買高檔，需謹慎
⚡黃金交叉／💀死亡交叉 → 金色／紅色特別標示

負值持續遞減 → 空方衰竭，強烈關注
由負轉正（穿越0軸）→ 動能轉強確認
正值持續遞增 → 多方增強，持股
整體遞減但末端回升 → 空方力竭，能量回升
最佳訊號：日KD低檔黃金交叉 + 日MACD由綠轉紅
💎 VCP型態與突破追蹤
VCP（波動收縮型態）是 Minervini 的核心進場型態
整理過程中波動幅度持續縮小，代表籌碼在集中
◈ 即將突破 → 密切關注　🚀 突破爆發 → 最強進場訊號
突破後10天追蹤（Pivot鎖定不浮動）：
Follow-through跟進 → 價量續攻，健康延伸
🎾 網球反彈確認 → 回調後創高，健康
縮量回測 → 守住Pivot，正常洗盤
帶量回檔 → 賣壓偏重，密切觀察
盤整過久（6天以上未創高）→ 動能減弱，重新評估
跌破Pivot → ❌ 假突破警示，隔天恢復VCP判斷
※ 有VCP時不需等分數，直接用型態進場
✦ 突破驗證（真突破／假突破）
✦ 有效突破：站穩Pivot之上，無長上影線
⚠️ 突破警示：有長上影線或量能不足，需觀察
❌ 假突破：跌破Pivot，考慮出場
長上影線定義：
上影線 > 實體×2　且　收盤落在當日振幅下半部
漲停 → 直接視為最強確認，無上影線疑慮
